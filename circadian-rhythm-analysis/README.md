# circadian-workshop

Begleitseite zum Workshop „Zirkadiane Rhythmen analysieren mit R“.

- `index.html` – Übersicht, Material, Originalarbeiten
- `periodogramme.html` – interaktive Erklärung χ²-Periodogramm (Falten) und Lomb-Scargle (Datenlücken)
- `feature-labor.html` – interaktive Kennwerte (IS, IV, RA, M10/L5, Cosinor) mit Reglern und Sonderfällen
- `analysebeispiele.html` – Schritt-für-Schritt-Analysen (MotionWatch, 2 × 3-Laufraddesign) mit Code und Abbildungen
- `r-pakete.html` – R-Pakete nach Aufgabe, Installation, Fallstricke
- `img/` – Abbildungen für die Analysebeispiele
- `workshop_R_public.zip` – R-Projekt mit simulierten Daten
- `style.css` – gemeinsames Stylesheet
- `slides.pdf` – hier das aus dem Folien-Deck exportierte PDF ablegen

Ordner in das Repository `christoph-berger.github.io` kopieren → erreichbar unter
https://christoph-berger.github.io/circadian-workshop/
