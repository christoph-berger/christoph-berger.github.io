Periodogramme interaktiv

Simulierte Maus im Dauerdunkel: 10 Tage Laufradaktivität in 6-Minuten-Bins, endogene Periode τ = 23,6 h. Welche Periode steckt in den Daten?

1 · Das χ²-Periodogramm faltet die Zeitreihe

Für jede Testperiode wird die Messreihe in Stücke genau dieser Länge geschnitten und zeilenweise untereinandergelegt. P ist die Zahl der Messpunkte pro Testperiode (Spalten), K die Zahl vollständiger Zyklen (Zeilen), N = K · P die Zahl der verwendeten Messpunkte. Stimmt die Testperiode, stehen die Aktivitätsblöcke senkrecht übereinander, das Spaltenmittel wird scharf und Qₚ groß.

K · N · Σₕ (x̄ₕ − x̄)² Qₚ = ───────────────────── ~ χ²(P − 1) Σᵢ (xᵢ − x̄)²

Gefaltete Tabelle – jede Zeile ein Zyklus der Testperiode

Spaltenmittel x̄ₕ – das mittlere Profil; Linie = Gesamtmittel x̄

Periodogramm – Qₚ über alle Testperioden; gestrichelt: Signifikanzschwelle p = 0,001

Bei Testperiode = 24 h ist der Bruch ohne den Faktor N genau die Interdaily Stability: IS = Qₚ / N.

2 · Lomb-Scargle kommt mit Lücken zurecht

Das χ²-Periodogramm braucht eine lückenlose, gleichmäßig abgetastete Reihe. Fehlen Daten – Sensor abgelegt, Laufrad blockiert, Batterie leer –, muss man sie vorher auffüllen. Lomb-Scargle passt dagegen für jede Frequenz eine Sinuskurve nach der Methode der kleinsten Quadrate direkt an die vorhandenen Messzeitpunkte an.

Bei diesem gut ausgeprägten Rhythmus finden beide Verfahren den Gipfel auch mit vielen Lücken. Der Unterschied liegt woanders: Das Auffüllen erfindet Messwerte und verflacht das Profil, und bei ungleichmäßig abgetasteten Daten – etwa einzelnen Blutproben oder Körpertemperatur zu unregelmäßigen Zeitpunkten – lässt sich das χ²-Periodogramm gar nicht erst anwenden. Lomb-Scargle arbeitet in beiden Fällen nur mit den tatsächlich gemessenen Punkten.

In R

# χ²-Periodogramm „von Hand“ qp <- function(x, P) { K <- length(x) %/% P xx <- x[1:(K * P)] m <- matrix(xx, nrow = K, byrow = TRUE) # die gefaltete Tabelle K * length(xx) * sum((colMeans(m) - mean(xx))^2) / sum((xx - mean(xx))^2) } P <- 200:280 # 6-min-Bins: 20–28 h Q <- sapply(P, qp, x = aktivitaet) plot(P / 10, Q, type = "l"); lines(P / 10, qchisq(0.999, P - 1), lty = 2) # Lomb-Scargle lomb::lsp(aktivitaet, times = zeit_h, from = 20, to = 28, type = "period")
