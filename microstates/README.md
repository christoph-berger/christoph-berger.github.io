# EEG Microstates companion site

Public URL: https://christoph-berger.github.io/microstates/

Files:
- `index.html` - landing page
- `visualization.html` - interactive EEG microstate explorer
- `handout.html` - six key points, responsive and print-ready
- `microstates-handout.pdf` - printable A4 landscape handout
- `poster.pdf` - add your conference poster under exactly this filename
- `styles.css` - shared site/handout styles
- `assets/qr-microstates.svg` - QR code pointing to the permanent landing page

The QR code should point to the landing page, not directly to a specific file, so the linked content can be changed later without replacing the printed QR code.
